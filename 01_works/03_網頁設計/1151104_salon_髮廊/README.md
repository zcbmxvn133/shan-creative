# 弌髮廊｜修13版型專題

以這次上傳的「修13.html」為版型基礎，保留區塊排列、文案、尺寸、照片輪播、會員中心彈窗、作品區、服務區及聯絡地圖。只將嵌入的樣式與互動程式拆成獨立檔案，將黑色改為深灰並保留暖米、木棕色。這是版型整理版，尚未完成完整 PHP 資料庫後端整合。

## 開啟介面

解壓縮後，開啟 public/index.html。圖片目前為有檔名的中性版位圖，因為原始檔未附照片。請依「缺少圖片清單.txt」將自己的照片放入 public/images/，以相同檔名覆蓋即可。MK01.png 為設計師照片，MK-logo.png 為標誌，其餘為空間、作品及服務照片；實際用途可對照 index.html 的替代文字。

## 檔案

- public/index.html：原版頁面結構與內容。
- public/css/style.css：原版排版與暖灰配色，已修正拆分後的背景圖相對路徑。
- public/js/app.js：原有互動程式與雲端連線。
- public/index.php：PHP（後端程式）首頁入口，輸出同一份 index.html；不是資料庫後端。
- public/images/：照片版位圖，請換回你的原圖。

## PHP 本機開啟

需要 PHP 8.1 以上。在此資料夾執行：

```sh
php -S 127.0.0.1:8000 -t public
```

瀏覽器開啟 http://127.0.0.1:8000/index.php 。正式主機的網站根目錄請設為 public。
